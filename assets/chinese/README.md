# Glow Sans SC / 未来荧黑

Source: https://github.com/welai/glow-sans/releases/tag/v0.93

Upstream font copyright: Glow Sans (c) 2021 Project Welai.
The original project license file is included as `GlowSans-OFL.txt` (SIL OFL 1.1).
The repository's MIT license applies to its build code, not to the font files.

Included styles: Normal Regular/Bold, Condensed Regular/Bold. The original 32,227 cmap mappings per style are preserved across the generated WOFF2 files. Font name and license metadata are retained.

Generated with `scripts/vendor_chinese.py` and `scripts/common_cjk.py` using fontTools. Common GB2312 Hanzi use groups of 256 codepoints, with separate basic Latin/punctuation and less-common glyph files. CSS Unicode ranges make loading selective. No runtime network service is required.
